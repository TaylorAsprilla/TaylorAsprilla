## 👋 Sobre mí

Soy desarrollador full stack y fundador de **Taylor Interactivo**. Construyo sitios web, software a la medida y **soluciones con IA y agentes** para negocios y organizaciones. Me importa que lo que entrego sea **rápido, claro y fácil de mantener**, y que ahorre trabajo real.

## 🧩 Qué hago

|  |  |
|---|---|
| 🤖 **IA y agentes** | Integración de LLMs en productos y procesos, agentes que usan herramientas y APIs, automatización de flujos de trabajo |
| 🎙️ **Procesamiento con IA** | Transcripción de audio, generación de documentos, extracción de información |
| 🛠️ **Software a la medida** | CRM, dashboards y sistemas administrativos |
| 🔌 **APIs y backend** | REST y GraphQL seguros, integraciones y autenticación (JWT, OAuth2) |
| 🌐 **Web y e-commerce** | Sitios corporativos, landing pages y tiendas online |
| 🔁 **Evolución de plataformas** | Mantenimiento y mejora de sistemas en producción |
